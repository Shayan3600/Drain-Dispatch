# Hackathon submission draft

DrainDispatch — See the blockage. Prevent the backup.

Residents often notice a leaf-covered drain or lingering water before anyone has a clear shared record. DrainDispatch turns those observations into organized evidence: a photograph or message, an editable description, an explicitly confirmed location and a community incident with follow-up history.

The Frutiger Aero interface pairs a Chapel Hill map with measured reporting activity. Nearby reports are offered as candidates; residents choose whether they concern the same physical drain. Community review stays separate from official municipal action. The platform links residents to existing Town reporting resources and does not file automatically or claim endorsement.

Built with React, TypeScript, Leaflet, Express and PostgreSQL. Gemini integration produces structured descriptions of visible evidence and uncertainty. A Photon Spectrum worker handles real provider messages through the shared reporting API, including secure location-confirmation drafts and persistent retry protection. Tiger Data event hypertables support reporting trends when the cloud database is connected.
