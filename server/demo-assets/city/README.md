# Local ClearFlow reference photographs

These ten original PNG attachments were supplied by the user for the local city demo on 2026-10-11. Copies preserve the original bytes, visible watermarks, and aspect ratios. See `server/src/db/cityReferencePhotos.ts` for the concern mapping and descriptions.

Run `node --import tsx scripts/city-showcase.ts --reference-photos` (or `scripts/start-city-showcase.ps1 -ReferencePhotos`) to create a fresh localhost-only database on a free port. It does not modify a running demo database or connect to a remote database. Its connection manifest is `.data/city-showcase-photos-active.json`; the original showcase manifest remains unchanged.

Photos illustrate blocked drains, standing water, and damaged drains. There is no supplied photograph matching the generic “other concern” scenario, so those retain clearly labelled illustrations. Some photos are reused across synthetic scenarios, not counted as independent photographic evidence. All ten are reachable through observation evidence. Records without photos remain to demonstrate the photo-only filter.

The seeded coordinates, dates, submissions, statuses and history are synthetic. Original photo locations, dates and authorship are unverified. The user confirmed permission to publish all ten images in Shayan3600/Drain-Dispatch on 2026-10-11; this records the user's confirmation, not an independent license verification or permission for other uses. The iStock / Michael Vi and kare11.com watermarks remain visible. No image is evidence of a city complaint, verified hazard, inspection or completed repair.
