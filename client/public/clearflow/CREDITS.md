## Custom interface source

Developed for Clearflow through iterative work with Codex. CSS bowls, grass, bubbles, TV housings, drain/pin/folder illustrations and SVG butterflies are in index.html, style.css and theme-v2.css. Animation code is in effects.js; report and aquarium interactions are in app.js. Recorded image prompts and audio synthesis sources are in dist/assets/credits/. System fallback fonts are not redistributed.
